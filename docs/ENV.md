# Environment Variables

Task Planner uses environment variables for configuration and secrets. 

You can copy the `.env.example` file to `.env` to get started.

| Variable | Required | Description | Example |
|----------|----------|-------------|---------|
| `GEMINI_API_KEY` | Yes | Your Google Generative AI API key used for schedule generation | `AIzaSyYourApiKeyHere...` |

Do not commit your `.env` file to version control.
